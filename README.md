# yuketang-bedside · 雨课堂病床看课助手

给**卧床、术后、行动不便**的用户当"鼠标手"：人真在看视频，AI 负责替他点播放、点下一节。

朋友住院/卧床期间的真实需求：能看屏幕，但每一次"点下一节"都要麻烦别人。这个项目把那些点击全部自动化了——它是一个**无障碍辅助工具**，不是一个刷课工具。

## ✨ 它做什么

- 🎬 **视频自动连播**：暂停自动续播、播完自动下一节、跨章自动衔接（自动跳过章节作业并留记录）——**这是默认模式，只做这件事，token 开销最小**
- 🔔 **弹窗自动处理**："继续观看/我知道了"自动点掉；视频内弹题会暂停，把题目、选项、推荐答案和理由展示给用户，3 分钟无回复才按推荐提交
- 📝 **（可选）作业协助**：整章题目提取 + 推荐答案 + 解析，用户一句"都按推荐提交"后才代为逐题点选
- 📚 **（可选）复习笔记**：每章知识点、每题解析写入 Markdown，期末一次性复习

可选功能默认关闭，用户明确提出才启用——有的同学只是需要在病床上把视频看完而已。
- 🔐 **登录一次**：扫码后登录态存本地，重启免扫码

## 🚫 它绝不做什么（边界写进了代码和 skill，不可协商）

| 绝不 | 原因 |
|---|---|
| 倍速 / 快进 / 跳过时间轴 | 视频必须 1x 真实看完——它是给"真在看"的人省点击的 |
| 未经确认提交作业答案 | 计入成绩的考核必须经过本人确认，AI 只当手、当讲解员 |
| 代考期末考试 | 永远本人完成 |

## 🚀 快速开始

```bash
git clone https://github.com/Bertrammmm/yuketang-bedside.git
cd yuketang-bedside/scripts
npm install
node yuketang.js "https://www.yuketang.cn/v2/web/index"
```

要求：Node ≥ 18，系统装有 Edge 或 Chrome（无需下载浏览器）。启动后屏幕上会弹出浏览器窗口，用手机雨课堂 App / 微信扫码登录一次。

本项目的 `SKILL.md` 是一份给 AI 助手（如 ZCode/Claude Code 类工具）的运行手册：把它放进 `~/.agents/skills/yuketang-bedside/`，之后对 AI 说"帮我在雨课堂看课"即可触发值守。

## 💡 让 AI 在后台值守：用 `/goal`

助手类工具的普通对话是一问一答——你不说，它就不动，视频中途卡住就没人管了。**用 `/goal` 命令给会话设一个目标**，AI 会在每轮之间被自动唤醒、持续巡检，直到目标完成：

```
/goal 请陪我看完雨课堂《XXX》课的全部视频，自动连播，弹题按 skill 规则处理
```

设好之后你就可以去休息了：AI 自己定期查状态、视频播完自动切下一节、异常自动修复、有弹题才来找你。这正是本项目作者在病床上全天候看课所用的模式。

## 🧩 工作原理

```
scripts/yuketang.js        Playwright 常驻脚本（Edge/Chrome + 持久登录态）
   │  自动巡检：视频暂停→续播；播完→点目录下一节；跳过"作业"条目
   │  自动跟随新标签页、自动点"继续观看"类弹窗
   ▼
127.0.0.1:7862  本地控制接口（仅监听本机）
   /status /tabs /switch /goto /next /play /pause /dump /shot /eval /answer
   ▲
   │ 轮询 + 决策（读题用截图视觉识别，因为雨课堂题目 DOM 做了字形混淆）
AI 助手值守
```

## 📖 实测踩坑记录（都在 SKILL.md §4）

- 雨课堂课时点击会新开标签页，监控需自动跟随
- 题目 DOM 中文被防爬字形混淆，`innerText` 是乱码 → 必须截图 + 视觉读题
- Git Bash 的 curl 传中文 JSON 会乱码 → 走 `wrap.js` 文件封装
- Windows 下重启需等待端口释放
